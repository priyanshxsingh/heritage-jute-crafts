# Heritage Jute Crafts

A modern, responsive website showcasing the beauty, versatility, and sustainability of jute products. Heritage Jute Crafts combines traditional craftsmanship with a clean, elegant digital experience to present eco-friendly bags and handcrafted collections.

## 🌿 About the Project

Heritage Jute Crafts is a frontend web project designed to showcase jute bags and their different categories through an attractive, user-friendly interface. The website focuses on sustainability, product presentation, and responsive design across desktop and mobile devices.

## ✨ Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
- **Hero Section** — A visually appealing introduction to the brand.
- **Product Collections** — Browse different categories of jute bags.
- **Interactive Navigation** — Smooth navigation between website sections.
- **Mobile-Friendly Collection Slider** — Browse collection cards with horizontal swiping on mobile.
- **Brand Story** — A dedicated section highlighting the brand's values and craftsmanship.
- **Video Section** — Embedded video content.
- **Contact Section** — Contact information and an enquiry form interface.
- **Modern UI** — Clean layouts, elegant typography, and a natural color palette.

## 👜 Product Categories

The website showcases the following collections:

- Promotional Bags
- Shopping Bags
- Tote Bags
- Sling Bags
- Crossbody Laptop Bags
- Fanny Packs

## 🛠️ Tech Stack

- **React** — Component-based user interface.
- **Vite** — Development server and build tool.
- **Tailwind CSS v4** — Utility-first styling.
- **Lucide React** — Icons.
- **JavaScript** — Application logic.
- **HTML5 & CSS3** — Web structure and styling.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/priyanshxsingh/heritage-jute-crafts.git
   ```

2. Navigate to the project directory:

   ```bash
   cd heritage-jute-crafts
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually:

   ```text
   http://localhost:5173
   ```

## 📦 Production Build

To create a production-ready build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

The generated production files will be available in the `dist` directory.

## 🌍 Deployment

The project can be deployed using [Vercel](https://vercel.com/).

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Select **Vite** as the framework preset.
4. Set the build command to `npm run build`.
5. Set the output directory to `dist`.
6. Click **Deploy**.
